# Análise de Vendas de E-commerce (Olist)

> **Status: em desenvolvimento.** O projeto ainda está sendo construído, então este README será atualizado conforme eu avanço.

Dashboard de vendas de e-commerce construído a partir do dataset público da Olist, usando **Python (pandas)**, **SQL** e **Power BI**.

## Objetivo

Transformar os dados brutos de um e-commerce real em informações que ajudem a entender o desempenho das vendas, passando pelo caminho completo de uma análise: limpeza e tratamento dos dados, consultas em SQL, visualização em dashboard e conclusões.

## O que o projeto pretende responder

Perguntas de exemplo (a lista pode mudar durante o desenvolvimento):

- Como as vendas evoluem ao longo do tempo?
- Quais categorias de produto vendem mais?
- Como estão os prazos de entrega?
- Em quais regiões estão os clientes?

## Tecnologias

- **Python** (pandas) para limpeza e tratamento dos dados
- **SQL** para consultas e agregações
- **Power BI** para o dashboard
